## 選定の基準

- **人物が写った写真は使わない。** Unsplash License は著作権を許諾するだけで、被写体の
  パブリシティ権までは処理していない。**5枚とも人物は1人も写っていない。**
- **他人の住まいの中を外から撮った構図は使わない。** 「ご利用者様が写っているお写真は使って
  いません」と書くサイトに、窓の中が見える写真を置くのは筋が通らない（下の落とした候補を参照）。
- **商標・店名の看板が読める写真は使わない。** 原寸で開いて文字を読んでから採用する。
- **日本の住まいの写真だけを選んだ。** 訪問介護は「お宅にお伺いする仕事」なので、
  欧米の郊外住宅（芝生・ガレージ・消火栓）は違和感が出る。
- 同じ写真をサイト内で使い回さない（5枚すべて別の場所で1回ずつ）。

## 差し替えの手順

1. 事業所で撮影したお写真（外観・入口・福祉車両・事務所内・スタッフ）を `images/` に置く。
2. `index.html` の該当 `<img>`（および `style.css` の `.hero-img` の `background`）の参照先と `alt` を差し替える。
3. **各写真の下の「※画像はイメージです」を消す。** 実写に変わったら不要になる。
4. フッターの `.ft-credit` の段落をまるごと削除するか、`photos from <事業所名>` に書き替える。
5. `style.css` / `script.js` の `?v=N` の N を1つ上げる（GitHub Pages のキャッシュ対策）。
